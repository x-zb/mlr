# Multi-layer Representations for Dense Passage Retrieval

## Requirements

`pip install -r requirements.txt`

## Dataset Preparation

Please refer to `scripts/prepare_dataset.sh`

## Experiments

The scripts to run the multi-vector retrieval experiments are located in the directory `scripts/multi-vector retrieval`.

The scripts to run the single-vector retrieval experiments are located in the directory `scripts/single-vector retrieval`.
